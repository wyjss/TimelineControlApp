## 第一轮：接口端口键与数据契约

问题：类型 `a/b` 的接口 `c` / 参数 `d`，与类型 `a` 的接口 `b/c` / 参数 `d`，都会生成 `in/a/b/c/d`。另一个合法组合是接口 `b` / 参数 `c/d`。共同注册对象节点时，调用节点参数因此重名。

修改仅位于已有 `objectCallPortKey`：各段先将 `%` 编码为 `%25`，再将 `/` 编码为 `%2F`。普通标识的端口键不变，宿主回调继续接收原始接口名和参数键。

验证：新增 `objectCallKeysRemainDistinct`，先在旧实现上复现 `definition.parameterKey`，再验证四组签名共同注册、配置覆盖保存重载、执行扇出和输出读取。框架及 Demo 构建通过，5/5 CTest 目标通过。Core-only 独立构建及 3/3 测试目标通过。

复评：数据身份冲突已解决，不需要新增 ID 类型或注册表抽象。长文本和 Demo 布局问题仍存在，进入第二轮。包含 `/`、`%` 的自定义接口端口键按现行规则重新生成；沿用项目现有的“不自动迁移旧端点”边界。普通 Demo 图不受影响。

## 第二轮：Demo 属性面板与完整诊断

将右侧属性区域改为纵向滚动，内容宽度跟随面板，禁止水平滚动；切换选中节点时回到顶部。省略的节点错误和底部状态信息可悬停查看全文。继续保留 README 约定的调试阶段直接关闭窗口行为。

新增正式 Demo 界面测试，直接加载 `demo/qml/Main.qml`，在最小与默认窗口尺寸下检查调用、设置和等待节点。默认控件高度与内容增高的情况分别验证，避免将“缺少某种组件”当作实际故障。

验证：旧版明确复现长诊断全文提示为空；在现有 `controlHeight` 增大至 128 后，等待实际布局再检查，删除按钮超出视口。新布局的 7 组数据全部通过（加初始化/清理为 9 passed），包括保留字段高度、无水平溢出、滚动到底、鼠标点击删除、撤销恢复、选择另一同类节点滚回顶部，以及状态栏和节点错误全文。真实源码的独立构建通过，6/6 CTest 目标通过。

复评：默认六组布局原本可放下，未将其夸大为故障；内容增高和诊断不可读的问题已得到验证。新测试目标也在真实独立构建中验证，补齐了根目录内 Qt Widgets 导入作用域；不依赖临时验证工程预先提供该目标。长名称和通用 GraphEditor 换图问题仍待第三轮处理。

## 第三轮：长名称、换图及空图视口

在原有标题和端口 Text 中限制可用宽度并省略；同一行两侧端口分配不重叠的文字范围，单侧使用完整宽度，原有鼠标区域显示完整名称。标题拖动和端口接线继续使用既有事件路径。

切换会话或不同图 ID 时重新调用现有首次适配流程。空图复用 `fit()` 既有的缩放 1、平移 0 分支，防止首个新节点沿用上一图的极小缩放。同图修改、撤销和模型重置保留用户视口。

验证：旧 QML 分别复现未省略的长文字和切换远坐标图后节点不在视口内。新 `longLabelsStayInsideCards` 验证中英文、双侧/单侧文字边界、完整悬停文本、实际接线、经过标题时连线预览继续跟随，以及标题拖动；`graphChangesRefitViewport` 验证同图撤销/重置、换会话、换图 ID、远坐标、空图、主题延迟提供及首节点创建。编辑器测试 6 passed（含初始化/清理），0 failed；完整框架与 Demo 构建及 6/6 CTest 目标通过。

复评：本次复现的端口身份、内容增高、诊断全文、长名称和换图边界均已覆盖。保留原有组件扩展入口和执行模型，没有引入新的视口状态或通用化层。
