# 数据结构与变更通知

本文记录当前公共接口及其实现边界。BlueprintFramework 面向多个宿主项目；Core 只依赖 Qt Core，Quick 提供图编辑投影和画布，Demo 提供示例对象、节点实现和特殊界面。

## 数据归属

| 数据 | 所有者 | 内容 |
| --- | --- | --- |
| 类型定义 | 宿主项目作用域内的 `NodeRegistry` | 稳定类型 ID、端口、参数、属性和接口声明，以及显示信息。追加注册后定义不可变。 |
| 图配置 | `GraphDocument` | 图 ID、节点与连线、位置和参数覆盖值。 |
| 编辑状态 | `GraphEditSession` 与各视图 | 一份文档共享撤销历史；选择、悬停、视口和拖动预览由各视图持有。 |
| 运行状态 | 每个 `GraphRuntime` | 启动快照、本次执行身份、动作输出、待发执行入口和在途调用。 |
| 业务对象 | 宿主项目 | 对象身份、配置、实时状态及外部请求。图中仅保存宿主可解析的引用。 |

图节点删除只删除图中的表示。宿主对象的生命周期和保存由宿主负责，同一对象可以被多张图或多个节点引用。节点配置更新通过文档提交，实时属性通知通过宿主通道传递，不用整图替换同步遥测。

`NodeRegistry`、`GraphDocument` 和 `GraphEditSession` 在编辑器所属线程使用。注册表必须比文档存活更久，文档必须比会话存活更久。节点定义指针在注册表存活期间有效；节点实例查询返回借用指针，文档编辑后需要重新查询。运行实例可以位于另一线程，跨线程前在文档线程创建值快照。

## 声明与图数据

```text
GraphData { id, nodes, connections }
NodeData { id, typeId, position, parameterOverrides }
ConnectionData { id, source, target }
Endpoint { nodeId, portKey }

SnapshotNode { id, typeId, parameters, ports }
GraphSnapshot { graphId, revision, nodes, connections }
```

节点和连线使用 `QUuid`。节点类型使用带模块前缀的稳定字符串，例如 `example.constant`。端口键、参数键、属性键和接口键分别在其声明范围内唯一，显示文案与键分开。连线始终保留完整的 `{nodeId, portKey}`，不以模型行号、显示名称或 QML 对象定位。

| 声明 | 主要字段与规则 |
| --- | --- |
| `NodeTypeDefinition` | 类型 ID、名称、描述、符号、分组、参数、端口、属性、接口和实例数量规则。 |
| `PortDefinition` | 稳定键、方向、显示名、`PortKind`、值类型和可选输入默认值。纯执行端口不声明值类型；`DataAndExecution` 仅用于输出，声明具体值类型，同时提供数据和执行能力。默认值仅用于数据输入。 |
| `ParameterDefinition` | 稳定键、值类型、默认值、字符串候选值、显示名、说明、数值上下界与整数约束。 |
| `PropertyDefinition` | 用 `ParameterDefinition value` 复用值声明，另声明 `writable`。值归宿主或运行实例。 |
| `MethodDefinition` | 稳定键、显示名，以及按值声明组织的输入、输出。具体调用由宿主实现。 |

属性的 `writable` 默认为 `false`，表示允许读取但禁止设置。Quick 的类型元数据保留该标记；设置属性只提供可写成员，没有有效可写目标时禁用输入与应用。宿主的实际写入入口必须再次检查权限，拒绝只读写入且保持状态不变。节点自身的配置参数仍由文档编辑，与对象属性写权限分开。

当前值类型为 `bool`、`number` 和 `string`。`number` 接受有限的 `int`、`uint`、`float` 和 `double`，不把字符串或布尔隐式转换为数值；`integer` 表示数值必须是数学整数，不是独立的 64 位整数类型。当前没有自定义值类型或无损大整数编码。 数据输入可声明 `anyValueType`，接受这三种具体值类型；它不用于参数、属性或输出，不接受执行信号，也不引入隐式类型转换。通用比较节点使用两个独立的 `any` 输入，并按实际类型决定运算结果。

字符串的 `allowedValues` 保存稳定值。数值的 `minimum`、`maximum` 为闭区间，缺少边界表示不限制。注册默认值、编辑、加载和宿主成员数据通过 `NodeRegistry` 的同一套类型及约束校验。宿主读写成员和处理接口输入输出时使用其正式声明，避免在界面和执行端分别维护范围。

`NodeData.parameterOverrides` 只保存配置覆盖值。缺少覆盖时读取定义默认值；没有默认值且没有覆盖表示未设置。调用 `setParameters` 时用无效 `QVariant` 清除覆盖，恢复默认或未设置状态。无效值不作为持久化参数值保存。

数据输入端口没有连线时使用 `defaultValue`；没有默认值则在求值时报错。默认值随声明或 `resolvePorts(const NodeData &)` 解析，不另存一份端口值。例如设置属性节点可由已校验的 `value` 参数派生输入默认值。

固定端口直接使用 `ports`。`resolvePorts` 可根据当前节点配置及稳定的成员声明返回完整的实例端口列表；不能依赖其他节点的可变配置或实时宿主状态。读取属性节点保存目标和成员引用，输出类型从成员声明解析，不保存 `memberType` 镜像。未绑定端口可暂时使用空值类型，此时不可连接数据线或求值；复合输出仍可连接执行输入。

`NodeRegistry::add` 追加不可变定义，拒绝重复类型 ID 或无效声明。`definitions()` 按注册顺序返回声明快照。`typeAdded` 经文档投影为 `typesChanged`，让已打开的会话刷新节点库；类型追加不改变文档 revision、保存点或撤销历史。不提供定义替换、热卸载或兼容类型别名。

## 数据与图的对应关系

一份文档管理一份图，可投影到多个画布。不同画布看到相同的节点、参数和连线，各自持有视口与选择。节点位置使用画布坐标，视口平移缩放只改变显示位置；连线几何由端口当前布局派生。

| 关联 | 定位方式 | 对应关系 |
| --- | --- | --- |
| 节点实例 → 类型 | `typeId` | 多个实例共享一个不可变类型定义。 |
| 连线 → 端口 | 图内的 `nodeId + portKey` | 先定位节点，再查询已解析端口。 |
| 文档 → QML | 节点或连线 ID | 模型行号只用于投影，编辑和选择使用稳定 ID。 |
| 节点 → 宿主对象 | 扩展定义的对象引用 | 宿主负责解释命名空间、查找和对象失效。 |
| 文档 → 运行实例 | `graphId + revision` 的启动快照 | 同一图可以同时创建多个独立实例。 |
| 一次动作 → 完成回调 | `runtimeId + executionId + callId` | 停止、重启或重复完成都不能误推进其他调用。 |

例如同一设备可以在配置卡片和操作节点中使用不同节点 ID，却引用相同的宿主对象。移动卡片、修改图内展示选择或绑定走文档；设备地址、实时播放状态和真实设备请求走宿主。对象失效时由宿主给出可定位诊断，不将对象指针写入图文件。

## 文档写入和变更边界

`GraphDocument` 是图配置的统一写入口。`canConnect` 无副作用，提交连线时再次检查端点、方向、类别、值类型、重复连线和输入占用。数据输入最多一个来源，执行输入可连接多个来源。各类输出都可连接多个目标。同一对端点只允许一条连线。连线类别由目标输入决定：数据输入接受数据或复合输出并校验值类型，执行输入接受执行或复合输出。执行线只传递触发信号，布尔值为假也不阻止已选中复合出口的执行。

节点类型可声明实例规则：

| 规则 | 行为 |
| --- | --- |
| `Multiple` | 同类型可以创建多个实例。 |
| `SinglePerDocument` | 每张图最多一个此类型实例。 |
| `UniqueByParameter` | 同类型按指定字符串参数的有效非空值去重。 |

创建、参数修改和整图替换都执行实例约束。冲突时 `EditResult.conflictingNodeId` 指向已有节点；Quick 的 `placeNode` 返回该 ID，供画布定位。

`reconnectConnection(connectionId, source, target)` 原子修改已有连线的端点并保留连线 ID，校验时只排除该连线自身的占用。成功后同一 ID 同时列入 `removedConnectionIds` 与 `addedConnectionIds`，投影读取提交后的端点；重连失败或端点未变时不产生通知和撤销记录。

一次编辑先构造并校验候选数据，再提交，最后发出一次 `changed(changeSet)`。失败或没有实际变化时不递增 revision；删除节点和关联连线属于同一次提交。通知回调中直接修改文档会被拒绝，调用方应在通知结束后提交。

```text
GraphChangeSet
  revision / reset
  addedNodeIds / removedNodeIds
  changedNodes [{ nodeId, positionChanged, parameterKeys, portsChanged }]
  addedConnectionIds / removedConnectionIds
```

`parameterKeys` 只列实际变化的配置键；派生端口改变时设置 `portsChanged`。参数及其派生端口一次原子更新，已连线端口必须保持存在、方向、类别和类型兼容；仅连接执行线的复合输出允许修改数据类型，连接数据线时继续保持类型约束。不兼容时整次修改失败，调用方先显式断线。当前不提供自动删线或重连回退。

`setParameters` 可一次更新多个相关参数，Quick 直接暴露该操作，并提供 `resetParameter` 清除单项覆盖。一次批量修改对应一个撤销步骤。撤销、重做恢复相同节点和连线 ID，按实际变化通知受影响的行并产生新的 revision。共享历史最多保留 100 步，保存点被截断时，文档继续标为已修改。

| 操作 | 文档通知 | 编辑器响应 |
| --- | --- | --- |
| 改参数及派生端口 | 节点、实际变更键和端口标记 | 更新节点和属性面板，重算相连线锚点。 |
| 提交移动 | 一个节点 ID，位置变化 | 更新位置及相连线几何。 |
| 增删连线 | 连线 ID | 刷新连线投影。 |
| 删除节点 | 节点与关联连线同批移除 | 先删除连线，再删除节点。 |
| 撤销删除 | 原节点与连线同批加入 | 先插入节点，再插入连线。 |
| 整图替换 | `reset` | 重建投影及编辑历史，清理失效选择。 |

## 从文档通知到 QML

`GraphEditSession` 提供节点 `QAbstractListModel`、只读连线列表、编辑入口、撤销历史、错误消息和结构化诊断。同一文档的多个视图绑定同一会话。外部整图替换会重建历史，因此不用于实时状态刷新。

节点模型投影 ID、类型、名称、位置、当前参数和已解析的输入输出端口。每个端口包含稳定键、显示名、值类型及数据与执行能力。连线投影按目标端口确定执行类别。`nodeTypes` 提供类型显示信息和参数声明；追加类型时单独通知。参数编辑和端口变化通过 `dataChanged` 报告实际角色，节点增删使用对应模型行通知。

`GraphEditor` 默认根据元数据生成节点库和属性面板。布尔使用复选框，字符串候选使用下拉框，其余参数使用文本或数值输入，并可恢复默认。Core 负责最终校验。字段提交失败时显示对应诊断，文本恢复为已提交值。宿主可注入 `palettePanel`、`inspectorPanel`、`nodeContents` 和 `nodeHeaders`，特殊对象选择器与成员操作仍由宿主实现。`GraphEditor.nodeStates` 接收宿主按节点 ID 提供的 `running`、`waiting`、`failed` 状态，由节点外壳显示，状态不写入图配置。

自定义节点内容及标题按 `typeId` 指定组件，根项声明 `property var node`，读取 `id`、`typeId`、`title` 和 `parameters`，以 `implicitHeight` 提供高度。节点外壳处理标题拖动和端口布局；端口锚点先使用节点局部坐标，再映射到画布视口。点击与拖线落点共用以端口锚点为中心的命中区域，范围随画布缩放，标签文字只用于显示。`ConnectionLayer` 接收已映射的线段端点。

端口支持双向拖线与依次点击。拖动只有一条连线的输入时，以该连线的来源输出作为固定端，放到另一输入后更换目标，并保留原连线的 ID 及其它分支。执行输入有多条连线时，可先选中其中一条再拖动输入以重接该连线。未选中该输入的连线时，从输入拖线会创建新连线。输出拖到已占用的数据输入时重接该输入的连线，拖到执行输入时添加一条连线。重连预览只隐藏正在重接的原线，文档在有效放置后一次提交；画布外释放、取消或无效放置保留原线。`connectionProposal` 由吸附预检和提交共用，统一端点方向及替换连线 ID，保证显示的合法性与实际提交一致；`completeConnection` 继续由点击和拖拽释放共用。

`GraphEditor.interactionCanceled()` 统一取消拖放、拖线、节点移动和平移；窗口失活、Esc、模型重置或切换图时结束预览，节点移动和平移恢复原位置。画布仅在自身获得焦点时处理 Delete 与撤销重做，文本控件保留自己的编辑行为。Demo 通过 `NodeDragSource` 共用节点库及成员的拖放预览和取消流程。

拖动期间只更新视图预览，释放时提交一次位置修改。首次适配在画布尺寸和节点项就绪后进行。视图按稳定 ID 保留仍存在的选择。宿主属性更新独立刷新卡片和预览，不写入图配置、不产生图撤销记录。节点规模和帧时间需要在目标机器上实测后再决定实例化或连线绘制优化。

## 运行契约

`GraphDocument::snapshot()` 在文档线程解析参数默认值和实例端口，返回不包含画布坐标的逻辑值快照。`GraphRuntime::start(snapshot, implementations)` 校验快照结构、端口和连接，并分别拒绝数据依赖环与执行流环，诊断包含可定位的节点和端口。启动后文档编辑不影响此实例，修改在下次启动生效。

运行实例的方法在其所属线程调用。计算和动作入口也在该线程执行；宿主负责把跨线程对象访问排队到对象所属线程。`Q_INVOKABLE` 不改变普通 C++ 调用的线程归属。回调捕获的宿主服务必须在运行实例停止前保持有效；运行实例不拥有宿主对象。

`RuntimeImplementations` 按类型 ID 提供运行实现：

| 注册入口 | 输入与结果 |
| --- | --- |
| `executors` | 接收 `ExecutionContext` 和完成回调，按类型共享执行器。按需求值在运行线程同步回调，执行线触发的动作允许异步完成，并可按 `callId` 取消。 |
| `evaluators` | 接收启动参数和按数据输入端口键组织的值，返回 `EvaluationResult{outputs, error}`。 |
| `actions` | 接收 `ExecutionContext` 和完成回调，完成时提供 `ActionResult{exitPort, outputs, error, branches}`。 |
| `cancellations` | 按当前 `callId` 请求取消宿主异步操作，可省略不支持取消的实现。 |

同一类型使用执行器或原有回调。执行器在运行实例所属线程启动和取消，Demo 的运行实例在主线程。对象成员声明供宿主校验；Core 不自动反射或调用 `QObject` 成员，也不维护第二份宿主属性值。

`evaluate(endpoint)` 接受数据输入、数据输出或复合输出；读取复合输出只取值，不触发执行线。输入沿连线读取上游，无连接时使用端口默认值；输出按完整端点解析。求值使用显式依赖栈，同一次求值共享上游结果，菱形依赖只计算一次；下次求值重新调用纯计算，能够读取宿主最新状态。输出必须包含全部声明的数据输出，不能包含未知键，且逐项符合已解析值类型。

`execute(executionOutput, entryOutputs = {})` 从执行输出或复合输出触发，返回本次 `executionId`。复合入口必须提供符合声明的本次数据输出。宿主可传入入口节点在触发时取得的数据，非空参数必须与入口声明的数据输出完全匹配。运行时在执行首个动作前发布这些值，下次执行时清空。受理前检查入口所连的各个目标，并沿只有一个执行出口的节点检查其所有目标的动作实现和必要数据依赖。遇到多出口节点时先检查该节点，选定出口后再预检所选分支。预检只检查图结构和已注册实现，宿主状态和计算结果在执行时检查。一个实例同时只受理一次执行，忙时显式返回诊断。执行总是排队启动，完成信号不会早于受理返回。每次触发执行输出时，其全部目标按连线顺序加入待执行队列，各分支可以同时等待异步结果。执行输入收到的每条信号都对应一次调用。

`ExecutionContext` 含 `runtimeId`、`executionId`、`callId`、`nodeId`、启动参数、数据输入和触发的执行端口。异步动作如需保留上下文，应复制所需字段。同步动作也调用同一个完成回调，框架统一排队处理结果。

成功动作通过 `exitPort` 选择一个执行出口，或通过 `branches` 触发多个已声明且互不重复的执行出口。两个字段都留空表示结束当前分支。每个选中的出口触发其全部连线，空出口跳过。各目标按所选出口和连线的顺序进入队列。各动作入口在同一运行线程调用，各分支可以同时等待异步结果。待发入口和在途调用全部完成后，本次执行才成功结束。上一步的结果在启动分支之前发布。复合出口须通过 `exitPort` 或 `branches` 明确选中，单纯返回其数据不会触发该出口的执行线；且、或、比较仍按需求值，真假执行路径继续由条件分支选择。数据依赖只读取本次执行中已经产出的值，需要等待前一步结果时应串接执行线。同一节点在一次执行中已有在途调用时，后续信号按到达顺序排队。数据输入在收到信号时求值并随信号保存，当前调用完成后再开始下次调用。其它已就绪节点可以继续执行。任一分支报告非空诊断时，运行时结束整次执行，清除排队信号，并请求宿主取消其它在途动作。结果输出与纯计算共用校验，下次执行前清空。

`stop()` 先使运行身份和所有在途调用失效，清除待发入口及结果，再请求宿主取消；活动执行收到 `runtime.cancelled` 完成诊断。完成回调可以从任意线程调用，结果排队回运行线程后再次核对三层身份，重复或迟到结果被忽略。运行对象销毁后仍可安全调用之前保存的完成回调。取消只代表请求，已发送的外部命令由宿主按实际能力处理。

`nodeExecutionChanged(nodeId, callId, running)` 在动作正式开始时报告 `true`，完成、失败或取消时报告 `false`；按需求值不发出该信号。宿主可按 `callId` 汇总多个运行实例中的活动节点，某一路完成不会清除其它调用的状态。`executionFinished(executionId, Diagnostic)` 报告受理后执行的成功、失败或取消。实时属性变化属于宿主通知，与某次接口调用完成分别处理。Demo 为每次属性事件使用独立运行实例，在通知时取得图快照和属性值。属性事件可以与手动流程并发，同一属性连续变化时各次执行持有各自的值。预览使用独立实例，事件值随触发传入正式执行。Demo 的 `trigger()` 从唯一的自动入口启动，每次触发为该次执行建立单调时钟。等待全局时间按目标偏移减去已经经过的时间来等待，所有分支使用同一个起点。

### 运行实现中的独立函数

以下私有函数承载共享规则或独立的回调处理。

| 函数 | 独立用途 |
| --- | --- |
| `evaluateValue` | 公开端点求值和动作输入共用端点解析、默认值及上游取值。 |
| `evaluateNode` | 用显式依赖栈计算上游，同一次求值复用节点完整输出。 |
| `validateOutputs` | 入口数据、纯计算返回与异步动作返回共用完整输出及类型检查。 |
| `validateExecution` | 入口受理和实际选中多出口分支时共用静态预检。 |
| `advance` | 既是排队执行的启动入口，也是动作完成后的继续入口，负责发起待执行动作。 |
| `complete` | 异步结果投回运行线程后的独立处理入口，核对身份、校验结果并推进。 |
| `finish` | 空执行、求值失败、动作失败和成功都需要统一清理本次执行并通知。 |
| `takeCancellations` | 停止和失败共用在途调用失效与取消回调收集。 |

其他新增的共享函数也有实际调用依据：

| 函数 | 独立用途 |
| --- | --- |
| `connectionProposal` | 吸附预检和提交共用端点及替换连线的解析，防止两处占用判断产生不同结果。 |
| `validateDataInput` | 端点求值、依赖遍历和执行预检共用输入类型与来源检查。 |
| `GraphDocument::applyData` | 整图加载与历史恢复共用校验和提交。 |
| `fitInitially` | 尺寸、可见性和节点项就绪时共用首次适配条件。 |
| `submitValue` | 文本、布尔和候选值控件共用提交及字段错误定位。 |

| `DemoGraph::startExecution` | 手动入口和属性事件共用快照启动、诊断和运行实例登记。 |

`nodeTypes`、`diagnostic`、`objectMembers` 等查询以及批量编辑、重置参数是 C++/QML 的公开属性或调用入口；其独立签名由 Qt 属性和元对象调用要求决定。

`CompletionGate` 只保护异步投递与 `GraphRuntime` 析构之间的对象指针访问。完成回调持有门闩，不持有运行对象；投递时加锁，析构先在同一锁下清除指针。运行对象存活时排队到其线程，销毁后直接忽略结果，避免跨线程检查对象存活与投递之间的竞态。

## 诊断与持久化

公共 `Diagnostic{code, message, nodeId, key}` 的空 `code` 表示成功。调用方根据稳定代码判断错误，消息负责展示；节点和成员或端口键提供定位，不通过解析消息决定行为。Quick 同时提供 `error` 字符串和 `diagnostic` 对象。

JSON 使用当前 `version: 1` 格式，只保存图 ID、节点 ID、类型、位置、参数覆盖值和连线端点。类型声明、运行输出、宿主对象指针和实时状态都不保存。加载先解析临时图并完整校验，成功后一次替换；未知类型、无效值或不支持的格式版本保留当前文档。保存使用原子写入。

现阶段直接同步更新公共模型、Demo 与现行格式，不提供旧接口适配、节点类型别名、版本迁移或缺失扩展占位。属性变化当前使用 `value` 复合出口；只有一个返回值的对象接口使用该返回值的稳定端口键作为复合出口。这两类节点原有的 `execOut` 连线需重接到现行出口，旧端点不会静默迁移。

## 验证与当前边界

当前检出的回归测试位于 `verification/`，覆盖深链求值、共享依赖、运行预检、撤销与宿主状态、画布外放线、嵌入视图适配和字段校验。独立构建还运行 Core 命令行示例，检查文档的基础编辑和通知。命令见 [README](../README.md#构建和验证)。

当前已实现追加式注册、配置派生端口、基本类型及成员声明、原子文档编辑、默认编辑界面和无环执行。二进制扩展加载与卸载、自定义值类型、循环、外部事件队列、通用变量节点、子图和执行调试面板均未实现；这些能力按明确用例单独设计，不以占位接口加入当前公共模型。
